iOS 26 · iPadOS 26

Automatic import on iOS 26

We recommend your personal iPhone that receives your schedule email. Set up the email automation on that device. Keep this guide open on another screen if that helps.

Start with step 1 →

This guide is for iOS and iPadOS 26. On version 27, use the shared shortcut offered inside CrewSchedule. Button names can vary with the system language.

Guide steps 1. Save the import shortcut 2. Find the file 3. Add the shortcut 4. Choose the email trigger 5. Create the actions 6. Get the email text 7. Use the email content 8. Send text to CrewSchedule 9. Save on one device 10. Check the next email If it does not work

Step 1 / 10

Save the import shortcut

In CrewSchedule, open Settings → Automatic import. Choose Share shortcut file, then save it to Files.

The file is named CrewSchedule Import.shortcut.

Next step →

Step 2 / 10

Find the file

Open Files and find CrewSchedule Import.shortcut in the folder you chose.

Return to this guide in CrewSchedule whenever you need the next step.

Next step →

Step 3 / 10

Add the shortcut

Tap the file and add CrewSchedule Import in Shortcuts.

Adding the shortcut does not create an email automation.

Next step →

Step 4 / 10

Choose the email trigger

In Shortcuts, open Automation, tap +, choose Email, set Sender to eFlightApplication@bristowgroup.com and Subject Contains to Schedule For, then choose Run Immediately.

Every filter must match. Check that this is the account that receives your schedule email.

Next step →

Step 5 / 10

Create the automation’s actions

After the email filter, choose Create New Shortcut. This creates the actions that run when a matching email arrives.

Next step →

Step 6 / 10

Get the email text

Add Get Text from Input and choose Shortcut Input.

This action receives the content from the matching email.

Next step →

Step 7 / 10

Use the email content

Tap Shortcut Input in Get Text from Input, expand the variable panel, and select Content.

This passes the actual email content into the text action.

Next step →

Step 8 / 10

Send the text to CrewSchedule

Below Get Text from Input, add Run Shortcut and choose CrewSchedule Import. Expand the action and set its Input to the Text result from Get Text from Input.

Check the Input field: choosing the shortcut alone is not enough.

Next step →

Step 9 / 10

Save on one device

Save the automation. Keep it enabled only on the device that receives and imports your schedule emails. If the shortcut offers Allow Running When Locked in its privacy settings, enable it if you want.

Disable the old automation before moving automatic import to another device.

Next step →

Step 10 / 10

Check the next schedule email

Allow access if Shortcuts asks. Return to CrewSchedule and confirm that you have set up the automation. After the next real schedule email arrives, check import history.

You can finish setup now; you do not need to send a test email. A manual shortcut run does not prove that the email trigger works.

If it does not work

Check that the email arrived in the right account, that both filters match, and that the automation runs immediately. Then check that the text result is connected to Run Shortcut. Open CrewSchedule import history for errors or schedules that need review.
